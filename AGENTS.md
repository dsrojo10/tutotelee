# Instrucciones para agentes

TutoTeLee es un proyecto familiar cuyo propósito es facilitar la comunicación con una persona con sordera severa y visión reducida. Toda decisión debe conservar ese propósito y la simplicidad de la experiencia.

## Reglas de trabajo

- Leer `SPEC.md` completo antes de modificar cualquier funcionalidad. Es la fuente de verdad de los requisitos funcionales.
- Mantener el proyecto simple y fácil de entender.
- Priorizar la accesibilidad, el máximo contraste, la legibilidad a distancia y la facilidad de uso.
- Usar la arquitectura definida en `SPEC.md` y evitar frameworks o dependencias innecesarios.
- Evitar la sobreingeniería: implementar solo lo necesario para el MVP y sus requisitos de seguridad y privacidad.
- Ejecutar los tests disponibles y el build antes de considerar terminada una tarea de implementación.
- Actualizar `README.md` si cambian la instalación, la configuración o el proceso de despliegue.
- No crear commits automáticamente; hacerlo únicamente cuando el usuario lo solicite de forma explícita.
- No convertir el proyecto en una plataforma genérica ni perder de vista su uso familiar.

## Alcance actual

Por ahora el repositorio contiene únicamente documentación y estructura inicial. No se debe asumir que Vite, Firebase o la interfaz ya están implementados.
